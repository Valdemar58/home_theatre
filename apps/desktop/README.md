# home_theater desktop — 0.5.0-rc.4

После входа основное окно показывает тот же интерфейс, что и веб: каталог, планы, комнаты, загрузки и плеер. Для просмотра выходить на сайт не требуется. Локальные служебные инструменты доступны в меню `home_theater → Локальные файлы и устройство`.

На странице тайтла выберите «Скачать на устройство», либо раскройте «Скачать на домашний компьютер» в плеере. Выберите свой компьютер, раздачу и серии. Это работает и из браузера: выключенное устройство получит сохранённое задание после запуска приложения. При неоднозначных номерах файлов загрузка ждёт уточнения. Готовую серию можно смотреть одному или разрешить тайтл комнате прямо в разделе загрузок.

Серверный путь сохранён. Общий интерфейс требует соединения с сервером; при его недоступности desktop оставляет локальную служебную панель. Подробности и проверки: [единый интерфейс](../../docs/unified-desktop-implementation.md).

Локальная библиотека, привязка устройства к аккаунту, подготовка FFmpeg, разрешения «тайтл × комната» и передача подготовленного видео в браузер участника. Прямой канал WebRTC с резервной HTTP-ретрансляцией через сервер. Зрителю desktop не нужен.

## Запуск

Node.js 22+, pnpm. Из этой папки:

```sh
pnpm install --frozen-lockfile
# Если pnpm заблокировал install scripts:
node node_modules/electron/install.js
node node_modules/ffmpeg-static/install.js
pnpm test
pnpm start
```

В окне укажите адрес сервера, нажмите «Открыть home_theater» и войдите в аккаунт внутри приложения. Вход в обычном браузере не переносит его cookies в desktop. Для локальных загрузок и управления этим компьютером из веба откройте Настройки → Мои устройства → Подключить этот компьютер и подтвердите устройство в том же окне. Разрешения комнатам выдаются отдельно. Найдите тайтл в каталоге, затем раздачу. Нажмите «Выбрать серии», проверьте номера файлов, оставьте нужные серии и нажмите «Скачать на устройство». Папка меняется в разделе загрузок. Автоматическая подготовка включена по умолчанию: после проверки скачанного файла FFmpeg создаёт отдельную MP4-копию. Исходник сохраняется. Готовый файл также можно подключить вручную через раскрывающийся блок.

В библиотеке разрешите доступ нужной комнате и откройте её кнопкой рядом. В плеере выберите устройство в «Источник комнаты». Друг подключается в браузере со своим аккаунтом и членством в комнате; устанавливать desktop ему не нужно. Разрешение действует на тайтл в комнате, включая следующие подготовленные серии. Отзыв устройства: веб-интерфейс → Настройки → Мои устройства.

Пауза/остановка загрузки сохраняет полученные части; после перезапуска продолжение запускается вручную и проверяет части заново. «Убрать запись» не удаляет исходные файлы. Пока идёт скачивание, BitTorrent также отдаёт полученные части пирам; после завершения выбранных файлов раздача закрывается. Подготовка требует дополнительного места. Прогресс: 80% загрузка + 20% подготовка.

Установленная сборка требует HTTPS. HTTP localhost разрешён только при разработческом запуске. Закрытие окна прекращает heartbeat и подготовку; скрытого фонового хостинга нет. На Linux без безопасного хранилища секрет привязки действует только до закрытия приложения.

## Пакеты

```sh
pnpm dist:win
# На Linux:
pnpm dist:linux
```

При уже загруженном Electron упаковщику можно передать `--config.electronDist=node_modules/electron/dist`. Linux build environment: `Dockerfile.build` (контекст — эта папка). Все команды используют `--publish never`.

Windows: `release/home_theater-0.5.0-rc.4-win-x64.exe`.
Linux: `release/linux/home_theater-0.5.0-rc.4-linux-x86_64.AppImage` при сборке в Docker с отдельным output mount.

Для просмотра откройте комнату в браузере и выберите своё устройство в «Источник комнаты». Участники должны войти в аккаунт и подключиться к просмотру. Окно desktop остаётся открытым. В плеере показан фактический маршрут и объём переданных данных. Подробности и границы проверки — [отчёт М6](../../docs/watch-together-m6-implementation.md).

См. [установку и обновления](../../docs/desktop-distribution.md) и [проверки локальной загрузки](../../docs/desktop-downloads-implementation.md). Это внутренние неподписанные RC-пакеты с ручным обновлением.

Поиск использует настроенный серверный Prowlarr; его API-ключи не передаются desktop. Поддерживаются torrent-файлы до 8 МиБ и magnet-ссылки BitTorrent v1, включая перенаправление Prowlarr на magnet. Для magnet desktop получает список файлов от пиров, не скачивая серии до выбора. Ожидание ограничено 90 секундами и отменяется кнопкой рядом с раздачей; при отсутствии пиров можно повторить попытку или выбрать другой релиз. Полученные метаданные сохраняются, поэтому после перезапуска заново искать список файлов не нужно. Чистый BitTorrent v2 и HTTP-перенаправления на внешние torrent-URL не поддерживаются. При неоднозначных именах номер серии задаётся вручную. Загрузка использует TCP, не uTP; сообщение библиотеки об отсутствии optional `utp-native` не означает сбой TCP. Для разработки с отключёнными install scripts необходимо также установить N-API prebuild `node-datachannel` (см. `Dockerfile.build`).

М7 автоматически заменяет недоступный хост разрешённой копией с тем же SHA-256 подготовленного MP4 и размером. Пока хватает буфера, видео не перезапускается. Для прямого переподключения обновите все desktop-хосты до 0.3.0-alpha.1. [Правила и проверки М7](../../docs/watch-together-m7-implementation.md).


Экран загрузок показывает свободное место каждого диска, место известных тайтлов и раскрываемую ленту серий. Корзина удаляет конкретный скачанный файл и подготовленную копию; остальные серии раздачи сохраняются, загрузка приостанавливается. У подключённого вручную файла удаляется только подготовленная копия и запись библиотеки, оригинал сохраняется. Используемую или подготавливаемую серию удалить нельзя. Для дисковой сводки и удаления из веба нужен desktop 0.5.0-rc.4 или новее.
