# Домашний кинотеатр

Календарь использует PostgreSQL: по умолчанию отдельный контейнер, внешний сервер настраивается через `.env`.
Миграции схемы выполняет `node-pg-migrate`; существующая SQLite переносится с проверкой данных при первом старте.
Подробности настройки, переноса и резервного копирования: [PostgreSQL](docs/postgresql.md).

Jellyfin + Sonarr/Radarr/Prowlarr + qBittorrent в Docker. Ищешь фильм или аниме в Seerr,
нажимаешь «Запросить», а система сама находит лучший релиз (4K/HDR, русская озвучка,
нужная студия), скачивает его, раскладывает по библиотеке и подтягивает субтитры.

```
Seerr ─► Sonarr (сериалы, аниме) ─┐            ┌─► qBittorrent ─► /data/torrents
   (поиск)    Radarr (фильмы) ─────────┼─► Prowlarr ┤                       │ hardlink
                                       │  (трекеры) └─ FlareSolverr          ▼
Jellyfin ◄──────────── /data/media ◄───┘                Bazarr (субтитры) ─► /data/media
```

| Сервис | Адрес | Зачем |
|---|---|---|
| Seerr | http://localhost:5055 | поиск и запросы, главный интерфейс |
| TorrServer | http://localhost:8092 | стриминг из торрента для «Смотреть сейчас» |
| Ollama | http://localhost:11434 | локальная LLM для рекомендаций |
| Аниме-календарь | http://localhost:5056 | даты выхода и финалов, списки, синхронизация с Shikimori |
| Jellyfin | http://localhost:8096 | просмотр |
| Sonarr | http://localhost:8989 | сериалы и аниме |
| Radarr | http://localhost:7878 | фильмы |
| Prowlarr | http://localhost:9696 | трекеры |
| qBittorrent | http://localhost:8090 | загрузки (порт: `QBIT_WEBUI_PORT`) |
| Bazarr | http://localhost:6767 | субтитры |

## Быстрый старт

Нужны Docker (с Compose) и Python 3.11+ (без дополнительных пакетов).

```bash
python scripts/init.py          # .env, ключи, пароли, каталоги
# отредактируй .env: DATA_ROOT, COMPOSE_FILE (GPU), RUTRACKER_USER/PASSWORD
docker compose up -d
python scripts/bootstrap.py     # связывает все сервисы между собой
```

Логин в Jellyfin/Seerr: `JELLYFIN_ADMIN_USER` / `JELLYFIN_ADMIN_PASSWORD` из `.env`.
qBittorrent: `QBIT_USER` / `QBIT_PASSWORD`. Sonarr/Radarr/Prowlarr из локальной сети пускают без пароля.

Что делает `bootstrap.py` (можно запускать повторно, шаги по отдельности: `--only sonarr,formats`):

- **qbittorrent**: категории `radarr`, `tv-sonarr`, `anime` с путями в `/data/torrents/...`
- **sonarr / radarr**: root-папки, hardlinks, имена файлов с `[tvdbid-…]`/`[tmdbid-…]` для Jellyfin, клиент qBittorrent (для аниме отдельный, по тегу `anime`), скрипт внешних озвучек
- **prowlarr**: FlareSolverr, связь с Sonarr/Radarr, трекеры RuTracker, Kinozal (если указан логин), Rutor, Nyaa, 1337x.
  Английские трекеры (тег `en`) идут в Sonarr напрямую, русские (тег `ru`) — через RU-индексатор календаря
- **recyclarr**: профили качества TRaSH Guides (`WEB-2160p` для сериалов, `UHD Bluray + WEB` для фильмов),
  размеры качества в Sonarr — анимешные (минимумы для западных сериалов отсекают обычные аниме-релизы).
  Для аниме профиль TRaSH не используется: он рассчитан на англ. фансаб (порог 100 баллов, «Dubs Only» = −10000) и отсекал бы русские релизы
- **formats**: форматы озвучек и студий из `profiles.toml`, их баллы и профиль `Anime RU`
- **jellyfin**: админ, библиотеки «Фильмы/Сериалы/Аниме», русская озвучка по умолчанию, NVENC/QSV
- **bazarr**: связь с Sonarr/Radarr, языки субтитров
- **seerr**: вход через Jellyfin, Sonarr/Radarr с профилями; аниме автоматически уходит в папку аниме
- **anime-calendar**: ключ Seerr для календаря, полки «Аниме-сериалы» и «Аниме-фильмы» на главной Seerr,
  индексатор «RU трекеры (anime-calendar)» в Sonarr

## Озвучки и студии

Всё задаётся в [profiles.toml](profiles.toml): у каждой студии (AniLibria, Dream Cast, AniDub, JAM…) есть
regex и балл. Sonarr выбирает релиз с наибольшей суммой баллов. Поменял баллы? Запусти
`python scripts/bootstrap.py --only formats`.

Как выбирать студию при просмотре:
- **Мульти-релиз** (несколько озвучек в одном файле) получает максимальный балл. В Jellyfin просто переключаешь аудиодорожку.
- **Внешние озвучки** (`RUS Sound/<Студия>/*.mka` в раздаче) скрипт [extra-tracks.sh](scripts/sonarr/extra-tracks.sh)
  кладёт рядом с эпизодом как `Эпизод.ru.AniLibria.mka`, и они появляются в списке дорожек под названием студии.
- Нужна конкретная студия для одного тайтла? Кнопка **«Озвучки»** на карточке аниме в календаре (см. ниже).

Стилизованные ASS-субтитры аниме лучше смотреть в **Jellyfin Media Player** (ПК) или Android TV-клиенте:
веб-плеер прожигает их в видео, а это транскодирование.

## Русские раздачи (RU-индексатор)

Sonarr не умеет разбирать названия раздач RuTracker (`Русское (S3) / Romaji 3rd Season / English [TV] [1-24 из 24]
[RUS(ext), JAP] ...`), поэтому русские трекеры подключены к нему не напрямую, а через модуль календаря
([apps/anime-calendar/src/server/ru](apps/anime-calendar/src/server/ru)). Для Sonarr это обычный Torznab-индексатор
«RU трекеры (anime-calendar)» с повышенным приоритетом.

```
Sonarr ──► RU-индексатор ──► Prowlarr (RuTracker, Kinozal: вход, Cloudflare)
              ├─ разбор названия: сезон, часть, серии, RUS(int/ext), качество
              ├─ какой это сериал и сезон в TVDB (AniList + anime-lists: «2nd Season Part 2» = S02E13–24)
              ├─ озвучки из описания темы (AniLibria, StudioBand, DEEP…)
              └─ Sonarr получает: «That Time I Got Reincarnated as a Slime S03 [WEBRip 1080p] [RUS(int), JAP] MVO, AniLibria RUS»
```

- **Автоматически**: запросы из Seerr/календаря и новые серии онгоингов находятся сами, Sonarr выбирает раздачу по баллам
  из [profiles.toml](profiles.toml) — теперь срабатывают и студии, указанные только в описании темы.
- **Вручную — кнопка «Озвучки»** на карточке аниме: список русских раздач сезона со студиями, типом перевода
  (дубляж / многоголосая), встроена ли дорожка в файл, качеством, сериями, размером и сидами. «Скачать» отправляет
  выбранную раздачу в Sonarr; если сериала там ещё нет, он добавится без автопоиска.
- **Помощник импорта**: внутри раздач файлы называются как угодно (`Slime S3 [01].avi`), и Sonarr не понимает, где какая
  серия. Календарь раз в 2 минуты проверяет очередь Sonarr и сам раскладывает такие загрузки по сериям (ручной импорт через API).
- Описания тем кэшируются на 30 дней. Первый поиск по тайтлу читает их до 15–20 секунд, остальное догружается в фоне.

Ограничения: если раздачи с нужной озвучкой на трекере нет — её не будет; 5–10% раздач оформлены нестандартно и могут
не распознаться (тогда — Sonarr → сериал → Interactive Search или Activity → Manual Import). Фильмы этот модуль не трогает:
их названия Radarr разбирает сам, RuTracker подключён к нему напрямую.

## Аниме-календарь

Свой сервис ([apps/anime-calendar](apps/anime-calendar), Next.js + PostgreSQL) в стиле Seerr. Вход той же учёткой Jellyfin,
у каждого пользователя свои списки.

- **Календарь**: месяц, неделя или лента (на телефоне по умолчанию лента). В ячейке месяца столько тайтлов, сколько
  помещается по высоте, остальное — счётчик «+N»; клик открывает панель дня с крупными карточками.
  Быстрые фильтры над сеткой: финалы, мои списки, «жду выхода», Япония, без коротких, оценка 7+.
  Финал определяется точно: это серия с номером, равным числу серий, по расписанию AniList (а не дата окончания).
  Время — в поясе устройства с меткой относительно Москвы («МСК», «МСК+2»).
- **Страница тайтла**: фон (баннер AniList, фон TMDB или кадр), галерея постеров и кадров с полноэкранным просмотром,
  «Следующая серия: 9-я · понедельник, 19 октября, 17:00 МСК · через 14 д», финал, расписание, связанное.
- **Фильтры**: формат, страна, жанры (включить/исключить), первоисточник, рейтинг, популярность, 18+, «только мои списки».
  Фильтры сохраняются в URL, ссылкой на отфильтрованный календарь можно поделиться.
- **Списки**: Смотрю / Жду выхода / Запланировано / Просмотрено / Отложено / Брошено / Пересматриваю, счётчик серий.
  На вкладке «Жду выхода» видны даты следующей серии и финала.
- **Запросить**: отправляет тайтл в Seerr с правильным сезоном TMDB (по базе [anime-lists](https://github.com/Fribb/anime-lists)),
  Seerr передаёт его в Sonarr с профилем Anime RU.
- Данные: AniList (расписание, жанры, оценка AniList), Shikimori (русские названия, описания и оценка MAL:
  Shikimori копирует её с MyAnimeList). На карточках показываются обе оценки, фильтр «Оценка от» работает по MAL. Ответы кэшируются, текущий и следующий
  месяц прогреваются в фоне, поэтому календарь открывается мгновенно.

**Смотреть сейчас** (без ожидания загрузки): кнопка «Озвучки» → «Смотреть». Раздача уходит в TorrServer, серии появляются
в Jellyfin в библиотеке «Стрим» (ссылка «Открыть в Jellyfin» через ~1 минуту). Jellyfin транскодирует через NVENC, озвучки
внутри файла переключаются в плеере. Первая минута может грузиться дольше, пока торрент набирает скорость. Озвучки
отдельными файлами (`RUS(ext)`) онлайн недоступны — для них «Скачать». Когда Sonarr скачал серию, ссылка на поток удаляется сама.

**Рекомендации «Для тебя» и граф** — на локальной LLM (Ollama, ничего не уходит наружу):
- На странице тайтла блок «Мои впечатления»: оценка, личные теги («так плохо, что смешно», «озвучка решает», «затянуто»…),
  озвучка, заметка. Это главный сигнал: модель учится не «любит исекай», а *за что* тебе понравилось.
- Каждый тайтл разбирается моделью (тон, тип юмора, темп, «насколько смешон своей нелепостью», зависимость от озвучки)
  и превращается в эмбеддинг. Кандидаты: рекомендации сообщества AniList к понравившемуся + похожие по смыслу.
- Модель пишет «портрет вкуса» и объясняет каждую рекомендацию одной фразой со ссылкой на основания.
- **Граф** (`/graph`): мои тайтлы, рекомендации и соседи; кластеры по содержанию с понятными названиями, поиск,
  фокус на кластере, «только моё». Цвет — кластер, белая обводка — мои тайтлы.
- Модели: `LLM_MODEL` (по умолчанию `qwen3.5:9b`, для RTX с 12–16 ГБ) и `EMBED_MODEL` (`bge-m3`) в `.env`, скачать —
  `python scripts/bootstrap.py --only ollama`. Без GPU работает медленнее (возьми `qwen3.5:4b`); без Ollama рекомендации
  остаются, но без портрета вкуса и объяснений.

**Синхронизация с Shikimori** (необязательно):
1. Создай приложение на https://shikimori.io/oauth/applications: Redirect URI `urn:ietf:wg:oauth:2.0:oob`, scope `user_rates`.
2. Впиши `SHIKIMORI_CLIENT_ID`, `SHIKIMORI_CLIENT_SECRET` и `SHIKIMORI_APP_NAME` (точное название приложения) в `.env`.
3. `docker compose up -d anime-calendar`, затем в календаре: Настройки → «Привязать Shikimori» → вставить код.

Первая привязка импортирует твой список с Shikimori. Дальше изменения уходят туда сразу, а изменения с Shikimori
подтягиваются каждые 15 минут. «Жду выхода» — локальный статус, в Shikimori он виден как «Запланировано».

На сервере поменяй `SEERR_PUBLIC_URL` на `http://<ip-сервера>:5055`, чтобы ссылки на Seerr открывались с других устройств.

## GPU

В `.env` → `COMPOSE_FILE`:
- NVIDIA: `docker-compose.yml:compose.nvidia.yml` (на Linux нужен `nvidia-container-toolkit`)
- Intel iGPU (мини-ПК): `docker-compose.yml:compose.intel.yml`, плюс `RENDER_GID`
- без GPU: `docker-compose.yml`

## VPN (опционально)

Добавь `:compose.vpn.yml` в `COMPOSE_FILE` и заполни `VPN_*`/`WIREGUARD_*` в `.env`
(провайдеры и переменные: [gluetun wiki](https://github.com/qdm12/gluetun-wiki)). Тогда qBittorrent ходит в сеть только через
туннель: VPN упал, торренты встали. Остальные сервисы ничего не замечают, адрес `qbittorrent:8080` сохраняется.

## Перенос на другую машину (мини-сервер)

```bash
# старая машина
python scripts/backup.py                       # → backups/home-theater-*.tar.gz (конфиги + .env)
# новая машина (Ubuntu/Debian)
git clone <repo> home_theater && cd home_theater
python3 scripts/restore.py home-theater-*.tar.gz
nano .env                                      # DATA_ROOT=/srv/media, PUID/PGID (id -u / id -g), COMPOSE_FILE
docker compose up -d
```

Медиатеку переносить отдельно (`rsync -aH --info=progress2 data/ server:/srv/media/`), `-H` сохраняет hardlinks.
Можно не переносить совсем: на чистой машине достаточно `init.py` → `up` → `bootstrap.py`.

## Каталоги

```
${DATA_ROOT}/
  torrents/{movies,tv,anime}   ← сюда качает qBittorrent (раздачи продолжают сидироваться)
  media/{movies,tv,anime}      ← отсюда смотрит Jellyfin (hardlink, места не занимает)
```
`torrents` и `media` обязаны лежать на одном диске, иначе hardlink невозможен и файл будет копироваться.

**Windows:** работает (проверено на Docker Desktop + WSL2), но bind-mount с NTFS медленнее, а первый старт
Sonarr/Radarr занимает пару минут. Для постоянной работы лучше Linux-сервер или `DATA_ROOT` внутри WSL.

## Если не качается

| Симптом | Что проверить |
|---|---|
| Индексатор красный в Prowlarr | Cloudflare: добавь индексатору тег `flaresolverr`. Блокировка провайдером: VPN-профиль или прокси в Prowlarr → Settings → Indexers |
| RuTracker не логинится | логин/пароль в `.env`, затем `bootstrap.py --only prowlarr`; сайт может быть недоступен без VPN |
| Sonarr «не находит» релизы аниме | открой «Озвучки» на карточке в календаре: если там раздачи есть, а Sonarr их не берёт — Sonarr → сериал → Interactive Search покажет причину (размер, качество, профиль) |
| Поиск сезона аниме идёт очень долго | Sonarr ищет аниме посерийно и по каждому альтернативному названию на английских трекерах (Nyaa ограничивает частоту запросов). Русские раздачи приходят сразу, см. Activity → Queue |
| Загрузка с RU-трекера застряла на импорте | помощник импорта разберёт её в течение пары минут; если нет — Activity → Queue → ручной импорт, лог: `docker logs anime-calendar \| grep "\[ru\]"` |
| Скачалось, но не импортировалось | Sonarr/Radarr → Activity → Queue: там написана причина. Все сервисы должны видеть один и тот же `/data` |
| RuTor есть в Prowlarr, но не в Sonarr/Radarr | известная проблема определения RuTor в Prowlarr: все результаты получают категорию «Other», и синхронизация их не видит. Искать на нём можно вручную в Prowlarr → Search. Основной русский источник — RuTracker |
| Раздача стоит на 0% | нет сидов (в Prowlarr у индексатора поставь минимум сидов) или закрыт порт `TORRENT_PORT` на роутере |
| Транскодирование грузит CPU | Jellyfin → Dashboard → Playback: должен быть выбран NVENC/QSV; проверь `COMPOSE_FILE` |

docker compose pull && docker compose up -d
