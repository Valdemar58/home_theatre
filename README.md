# home_theater

Личный эксперимент: медиахаб для планирования, отслеживания и совместного просмотра аниме, с мангой, ранобэ и анализом содержания. Общий интерфейс в вебе и desktop; desktop скачивает и раздаёт локальные серии.

**Статус:** подготовка 1.0. Работоспособность сценариев фиксируется в [исходной проверке](docs/release-1.0-baseline.md); стабильный выпуск ещё не принят. Windows — целевая stable-платформа, Arch — preview.
