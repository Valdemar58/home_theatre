# М4 — циклы, прогресс группы и исправления истории

Реализация: 17 ноября 2026. Базовые правила — `watch-together-specification.md`, решения Q6–Q7, Q12–Q16, Q18–Q21. Интерфейс продолжает существующий дизайн; направление — сдержанная элегантность.

## Что реализовано

- Личные циклы первого просмотра и пересмотра. 10% уникальных фактически воспроизведённых участков одной серии запускают статус «Смотрю» / «Пересматриваю»; 80% засчитывают серию. Знаменатель — полная длительность файла, без вычитания OP/ED. Перемотка не добавляет покрытие, повтор одного участка не удваивает его.
- Ручная отметка конкретной серии. Последняя серия сама по себе не завершает тайтл: учитывается покрытие всех серий. Старые счётчики сохраняются как явная исходная отметка, без выдуманных событий и интервалов.
- Незавершённая попытка продолжается для того же файла с той же длительностью. Другие версии не объединяются автоматически. Поздние отчёты завершённой попытки не меняют новый цикл.
- Неактивность: 60 дней по умолчанию, личная настройка от 1 до 3650 дней, 0 отключает правило. Первый просмотр становится брошенным, пересмотр возвращается в просмотренное; исходное завершение и история цикла сохраняются. Ожидание релиза не входит в срок, отсчёт начинается после обнаружения новой непросмотренной серии. Проверка выполняется при запуске фоновых задач и затем ежечасно.
- Независимый результат встречи: конкретные серии и фактические зрители. Личный просмотр вне встречи, новые участники и их личные счётчики не меняют результат группы. Групповой прогресс складывается из результатов встреч, а не из минимального прогресса участников.
- Исправление результата существующей встречи организатором: серии слотами, несколько тайтлов, выбранные участники, комментарий и обязательный предпросмотр групповых и личных изменений. Подходит для просмотра офлайн или во внешнем сервисе, включая ранее несостоявшуюся встречу.
- Каждое исправление сохраняет авторство и журнал. Измеренные просмотры и более поздние личные циклы не удаляются. Участник может отменить сделанную за него отметку в настройках; повторная правка организатора не восстанавливает её молча. Отмена единственной ошибочной отметки возвращает предыдущий личный статус.
- Встреча без фактического старта через два часа после назначенного времени становится «Не состоялся». Её результат можно исправить позднее.
- Jellyfin использует точные серии и ключи событий, чтобы повтор синхронизации не создавал повторный просмотр. Старая команда совместных личных отметок явно названа «Личные отметки с друзьями» и не выдаётся за результат групповой встречи.

## Где пользоваться

В комнате: **История сеансов → Исправить результат → выбрать серии и участников → Проверить изменения → Сохранить результат**. Без выбранных участников меняется только результат группы. Намеренно пустой список участников сохраняется при повторном открытии редактора.

В настройках: **Прогресс и история просмотра** — срок неактивности, циклы, отмена отметок организатора. В плеере ручная отметка относится к выбранной серии.

## Хранение и совместимость

| Данные | Назначение |
|---|---|
| `playback_coverage` | Накопленные уникальные интервалы попытки воспроизведения |
| `watch_cycles` | Личный цикл, исходный статус и счётчик, активность и исход |
| `watch_episode_events` | Точные серии, источник, автор и отмена события |
| `meeting_coverage` | Отдельные свидетельства просмотра в конкретной встрече |
| `meeting_history` | Журнал исправлений результата встречи |
| `watch_preferences` | Личный срок неактивности |
| `watch_sync_receipts` | Защита от повторного импорта собственных событий Jellyfin |

Четыре добавочные миграции `1794873600000`–`1794873603000` поддержаны PostgreSQL и SQLite. Существующие списки остаются совместимой проекцией; подробные серии хранятся отдельно. Исправления проверяют права и ревизию встречи, устаревшее сохранение отклоняется. Старые встречи без подробных свидетельств не получают выдуманный результат.
