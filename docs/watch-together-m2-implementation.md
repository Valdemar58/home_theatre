# М2: редактор будущих сеансов

Дата: 11 ноября 2026. Область: создание/редактирование плана, не исполнение всего вечера в плеере.

## Что реализовано

- Несколько тайтлов из комнаты, перестановка вверх/вниз, удаление блока.
- По умолчанию все серии, доступные к началу встречи. Сетка раскрывается; сброс и выбор всех, одиночное переключение, клавиатура и диапазон мышью. Диапазон основан на исходном снимке выбора. Mouse pointer capture завершает операцию и при отпускании вне сетки.
- Выбранность показана рамкой, серые серии можно выбрать повторно. Для больших сезонов сетка разбивается по 100 слотов; выбор всех действует на весь сезон.
- Перерыв после каждого блока перемещается вместе с ним. Последний перерыв хранится, но не входит в окончание.
- Время начала и IANA-пояс; несуществующее локальное время не сохраняется, при осеннем повторении часа выбирается конкретное вхождение. Расчёт учитывает смену даты.
- Длительность берётся из каталога, неизвестная оценивается в 24 минуты. Исключение OP/ED — оценочные 3 минуты на серию длиннее 3 минут. Короткие выпуски не обнуляются. Это не настройка воспроизведения или зачёта просмотра.
- Карточка и история показывают все блоки и точные наборы серий; карточка — интервалы и примерное окончание, стопку обложек и действие редактирования.
- Сервер проверяет доступ, принадлежность тайтла комнате, диапазоны, выход к началу встречи, паузы, дату, пояс и revision. Несовместимая параллельная запись отклоняется; начатые и завершённые планы не редактируются.
- Старые single-title записи читаются адаптером. Новые планы хранятся как упорядоченный JSON snapshot с серверными длительностями; старые поля сохраняются как проекция первого блока.
- Фоновая подготовка использует каждый выбранный эпизод каждого блока без заполнения пропусков. Устаревшая revision не помечает новый план подготовленным и не запускает его.

## Границы

Серые слоты пока используют **прежний общий прогресс** (минимум личных прогрессов участников), что явно подписано в редакторе. Это не новый учёт результата групповых встреч: соответствующая модель остаётся М4. Историю результата нельзя восстанавливать из прежнего статуса done, поэтому выдуманные подтверждённые просмотры не создаются.

Автоматическое исполнение последовательности, синхронные перерывы, автопереходы между тайтлами и план в desktop-хостах — последующие вехи. Текущий планировщик открывает комнату на первом выбранном эпизоде; новый план сохраняется для дальнейшего исполнения. Нельзя считать весь вечер уже реализованным по наличию редактора.

Будущие серии разрешаются только по явной дате из доступных метаданных nextAiringEpisode, без предположения о недельном шаге. Более поздние серии с неизвестной датой остаются TBA. Отсутствие метаданных консервативно блокирует выбор. Полный календарь релизов и достоверные сегменты OP/ED в оценку пока не интегрированы.

## Проверки

- TypeScript и production-сборка Next.js, сборка Docker.
- 20 тестов в четырёх профильных файлах на SQLite.
- 13 интеграционных тестов на отдельной PostgreSQL 17. Файлы запускать с `--no-file-parallelism`: они очищают общие тестовые таблицы и при параллельном запуске конфликтуют. Рабочая база для этих тестов не использовалась.
- Миграция up/down/up на временной PostgreSQL прошла. Down удаляет новые планы и revision, поэтому не является безопасным пользовательским откатом.
- Браузер на 5056: создание двух блоков, выбор 1 и 3, drag 1–6, перестановка, OP/ED, сохранение, reload, повторное открытие редактора, изменение перерыва с 10 на 11 минут. Изменения проверялись в существующей тестовой комнате 4, без приглашений.
- Визуальные размеры: текущий viewport, 1440 и 390. Точная проверка контраста, реальный touch-девайс и совместное воспроизведение двух устройств не выполнялись.

## Внедрение и откат

Образ собирается из worktree a753, запускается только anime-calendar через compose основной папки с `--no-deps --no-build`. Остальные сервисы не пересоздаются. Tag: `home-theater/anime-calendar:m2-editor-20261111`, рабочий alias `:local`. Резерв предыдущего приложения `:pre-m2-editor-20261111`; dump `/data/backups/pre-m2-editor-20261111.dump` в постоянном томе календаря.

Миграция `1794441600000_session-editor.sql` добавляет nullable plan_json и revision с default 1. Откат приложения возможен без удаления колонок, но прежний UI видит лишь проекцию первого блока: не использовать старый планировщик для автоматического исполнения новых многотайтловых встреч. Перед откатом отменить/приостановить такие планы; JSON сохранить для возврата новой версии.

Исходники основной папки по-прежнему не заменены: rebuild из неё вернёт прежний код. Перед дальнейшей сборкой переносить изменения штатным git-процессом.

Дизайн расширяет текущие PRODUCT.md/DESIGN.md, не меняя палитру. Направление и границы: [session-editor-direction.md](session-editor-direction.md).

Независимый Impeccable finish review по финальным исходникам и снимкам: ship в рамках M2, блокеров не найдено. Подтверждены отступы секций, полноценная ширина карточки сеанса на телефоне и контекстное пустое состояние добавления. Проверка не является аудитом контраста, полного клавиатурного прохода или реального touch-устройства и не распространяется на M3/M4.
