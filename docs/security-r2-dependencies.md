# Уязвимости зависимостей при R2

Исправления не скрывают сообщения аудита и не исключают уязвимости из проверки.
В CI добавлены обязательные npm/pnpm audit с порогом low; ошибка аудита блокирует PR.

| Цепочка | Исправление | Проверка |
|---|---|---|
| Сервер: glob | Override 14.0.2 | Сборка Next, миграции, SQL и тесты PostgreSQL |
| Сервер: minimatch >=7 <11.0.1 | Override 11.0.1 | Полный серверный прогон |
| Desktop: minimatch >=7 <11.0.1 | Override 11.0.1 | Тесты и упаковка Windows/Linux |
| Desktop: ip 2.0.1 через bittorrent-tracker | Удаление зависимости и минимальный фикс парсера UDP | Тест IPv4 из wire-формата и нулевого адреса, проверка отсутствия ip |

Для ip нет исправленной версии. Патч `patches/bittorrent-tracker@11.2.3.patch`
заменяет единственный вызов преобразования 32-битного IPv4 прямым чтением четырёх
байтов пакета. Нулевой адрес по-прежнему использует адрес отправителя. Пакет ip
исключён из графа через pnpm override; frozen lockfile и проверка применения патча
не позволяют молча потерять фикс при установке. При обновлении bittorrent-tracker
патч нужно пересмотреть и удалить, если upstream устранит эту зависимость.
Это не общее переписывание адресного парсинга или отключение SSRF-проверок.

Старые minimatch 3/5 не относятся к обнаруженному диапазону уязвимости и намеренно
не заменяются несовместимой major-версией. Нет принудительного обновления всех
транзитивных зависимостей без проверки их вызывающего кода.

Локально npm audit сервера и pnpm audit desktop показали 0 уязвимостей всех уровней.
После попадания lockfiles в main через PR #41 API GitHub подтвердил **0 открытых
Dependabot Alerts**: обнаруженные ранее #12–#15 закрыты обновлёнными зависимостями.
Аудит зависимостей не является обещанием отсутствия всех возможных ошибок приложения.

## Actions

PR #31 обновил закреплённые по SHA checkout/setup-node/upload-artifact до актуальных
версий. Это устраняет предупреждения об устаревшем runtime этих Actions.
Обязательные тесты, скан истории на секреты и минимальные права workflow сохранены.

Сообщения об устаревших транзитивных пакетах сборщика и experimental node:sqlite
не равны открытой уязвимости. Их нельзя просто подавлять ради зелёного журнала;
обновления upstream и переход Node рассматриваются отдельно, если необходимы.

В CI R2 44618307222 предупреждений-аннотаций GitHub Actions не обнаружено;
финальный CI кода 44620227727 также полностью успешен.
В текстовых журналах остаются experimental node:sqlite в Node 22 и deprecated
whatwg-encoding 3.1.1 через cheerio → encoding-sniffer. Принудительная подмена
такого пакета другим API ради удаления строки журнала не выполнялась.
