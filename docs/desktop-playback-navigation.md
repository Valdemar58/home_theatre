# Desktop: возврат, fullscreen и восстановление медиапути

20 ноября 2026. Исправления #45 и #47, эксплуатационная проверка #39.
Кандидат desktop — `0.5.0-rc.7`; приёмка владельцем остаётся отдельной стадией.

## Изменения

- В общем верхнем баре появилась кнопка «Назад». Она отключена без предыдущей
  страницы, обновляется после полной и SPA-навигации. Возврат доступен также через
  меню, Alt+Left и системную команду мыши browser-backward.
- IPC возврата принимает команды только от главного frame текущего окна приложения.
  Доступ к файлам и токенам через новый элемент не добавляется.
- Вместо общего запрета permission fullscreen разрешён только главному frame
  текущего окна с origin настроенного сервера. Остальные разрешения, сторонние
  frame и automatic-fullscreen остаются запрещены.
- При DOM fullscreen верхний desktop chrome скрывается, после выхода возвращается.
  Учтён fullscreen как корневого html, так и вложенного плеера.

## Проверки desktop

- Windows, настоящий Electron 45.3.3, отдельный профиль и локальные HTML-страницы:
  неактивная кнопка на первой странице, возврат со второй, возврат после pushState,
  вход/выход fullscreen, скрытие chrome и проверка его компоновки на ширине 390 px.
- Alt+Left отдельно проверен настоящим вводом Windows через Computer Use. CDP
  dispatchKeyEvent не выдаётся за проверку нативного меню/сочетания клавиш.
- 17 тестов desktop: torrent/magnet через реальный локальный BitTorrent, библиотека,
  FFmpeg-подготовка, команды, transport и ограничения fullscreen.
- Негативные проверки: чужое окно, iframe, посторонний origin, opaque URL, камера,
  clipboard и automatic-fullscreen не получают разрешение.

HTML-стенд проверяет оконную оболочку, а не воспроизведение настоящей серии.
Полноценный сеанс с другом, ручные переходы и реальная проверка Arch остаются
отдельными критериями приёмки 1.0.

## Dev-медиапуть

С сохранёнными конфигурациями запущены Sonarr, Prowlarr, qBittorrent,
TorrServer, stream-router и FlareSolverr. Перед запуском сохранены копии
конфигураций. Другой проект не перезапускался, образы сервисов не обновлялись.

Проверено из backend:

- Sonarr и Prowlarr отвечают по API; qBittorrent принимает вход и отвечает версией.
- В библиотеке доступны 25 готовых файлов серий.
- Реальный запрос `/api/play` готовой серии вернул 200, одну аудиодорожку
  и четыре дорожки субтитров. Через цепочку HLS получен бинарный видеофрагмент
  размером 1 МиБ с HTTP 206 и content-type video/mp4; сессия остановлена.
  Прогресс просмотра и просмотренные интервалы не отправлялись.
- Поиск Nyaa дал 75 magnet-раздач. Реальный desktop API с существующей привязкой
  вернул 100 результатов и валидный magnet-дескриптор (200). Секреты индексатора
  и токен устройства в отчёт не выводились.

Это не означает скачивание и просмотр новой внешней раздачи целиком. Для #39
ещё нужны приёмка выбранной раздачи на устройстве и полного пути подготовки/
совместного просмотра. 1337x сообщает о прежней недоступности; успех других
индексаторов не объявляет все источники исправными.

YouTube (#46), анимация «Барабана» (#43), карточки (#44) не входят в этот инкремент.
Безопасность iframe fullscreen не ослаблялась для обхода проблем YouTube.

## Установка кандидата

Установщик применяется поверх существующего Windows-приложения, с сохранением
каталога данных и устройства. Закрыть приложение после завершения активных задач,
установить кандидат и открыть прежний ярлык. Linux AppImage — preview;
упаковка и Linux-тесты не заменяют GUI-проверку на настоящем Arch.

Владельцу: проверить возврат из тайтла/плеера/книги, запуск подготовленной серии,
fullscreen → Esc → fullscreen, сохранение привязки и текущего контекста.
