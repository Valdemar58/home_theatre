# Сквозная проверка desktop → web — 2026-11-19

Полный локальный сценарий проверен 19.11.2026 на коде desktop 0.5.0-rc.4 и веб-образе ui-fixes-20261119. Использованы чистый desktop-профиль, изолированная база на 5057, два синтетических аккаунта, тестовый провайдер входа и индексатор. Авторизация приложения, очередь команд, BitTorrent, FFmpeg, разрешения, WebRTC и синхронизация настоящие. Рабочая база и пользовательская медиатека не менялись.

Границы: вход через публичный OIDC, NAT/VPN сети друга, TURN/relay через интернет и GUI Arch не проверялись. Windows запускался из исходников текущей версии с отдельным профилем, а не повторной установкой NSIS. Ручной переход на другую серию вне плана сеанса намеренно устанавливает playing=false в server/rooms.ts:310; для запуска требуется Play. Автопереходы по плану этим прогоном не проверялись. BitTorrent может создавать файлы-заглушки и получать граничные части невыбранных файлов; в библиотеку импортированы только серии 1 и 3.
