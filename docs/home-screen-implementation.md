# Общая главная и desktop-панель · 2026-11-18

Главная находится на `/`: один React-интерфейс для браузера и desktop. Календарь остаётся на `/calendar`. Логотип и новый пункт навигации ведут на главную; привязанный desktop открывает её при запуске.

## Поведение

- Продолжение: до шести текущих просмотров, основной — по последней активности. Учитываются отдельные просмотренные серии текущего цикла, пропуски, сохранённая позиция и объявленные даты выхода. Невышедшая серия не получает действие запуска. Завершённый тайтл не начинает пересмотр автоматически.
- Ближайший сеанс: только комнаты, в которых пользователь состоит; приглашения не считаются членством. Активный сеанс имеет приоритет, просроченные более чем на два часа планы не показываются. Порядок тайтлов, серии, приблизительное время и перерывы берутся из сохранённого плана. Подтвердившие участие показаны аватарками.
- Загрузки: собственные неотозванные устройства, активные задания, ожидающие команды, состояние связи и время офлайн-снимка. Полоса содержит 80% скачивания и 20% подготовки. Переход открывает загрузки выбранного устройства. Администратору также доступна очередь медиасервера; ошибка источника не выдаётся за пустую очередь.
- Desktop: компактная перетаскиваемая панель в цвет canvas, системные кнопки окна и меню локальных инструментов. Изолированный preload не экспортирует токены, файловые операции или IPC хоста веб-странице. Отдельный сигнал открывает только фиксированное меню и принимается только от главного frame окна приложения.
- Личный desktop-плеер теперь восстанавливает сохранённую позицию, если явная стартовая позиция не задана. Явное начало с нуля и позиция общей комнаты сохраняют приоритет.

## Проверки

- TypeScript: без ошибок.
- Сервер: 550 тестов прошли, 1 существующий пропуск. Новые проверки: доступность серий, пропуски в цикле, продолжение нестандартного порядка, членство/приглашения, приоритет активного сеанса, изоляция устройств и возобновление desktop-видео.
- Desktop: 14 тестов прошли на Windows и в Linux-контейнере; реальные локальные torrent/magnet и FFmpeg входят в существующий набор.
- Windows UI: новый бар и его меню проверены в Electron. Браузер: заполненная главная, переход к комнате, мобильная ширина 390 px без горизонтального переполнения.
- Свежая проверка Impeccable: ship, без обязательных исправлений в данном объёме. Доказательства: `.impeccable/review/home/`.
- Windows NSIS и Linux AppImage версии `0.5.0-rc.2` собраны. Содержимое обоих ASAR сравнено с исходниками, включая новый preload. SHA256: `apps/desktop/release/SHA256SUMS-0.5.0-rc.2.txt`.

Настоящий Arch GUI остаётся непроверенным, как ранее согласовано. Тестовые синтетические встречи и загрузки находятся только в изолированной базе, не в рабочем аккаунте. Скриншоты тестового аккаунта используют серые заглушки обложек.

## Развёртывание

Образ: `home-theater/anime-calendar:home-20261118`. Резервная копия перед обновлением: `/data/backups/pre-home-20261118.dump`; образ для отката: `home-theater/anime-calendar:before-home-20261118`. Схема БД не менялась. Обновляется только контейнер anime-calendar на 5056.

Развёрнуто: контейнер `healthy`, `/api/health/database` — HTTP 200. Финальный образ: `sha256:1d354f5b2f00f4809c60584682aef1c60cb6a5c4c99be0534035a0614ae49633`.

Рабочая страница проверена в авторизованном браузере: реальные обложки и два текущих просмотра отображаются, встреч и привязанных устройств у проверенного аккаунта нет. Очередь медиасервера сейчас недоступна (внешний сервис загрузок не запущен); главная показывает это явно, остальные блоки работают независимо. Тестовый контейнер, desktop и прокси после проверки остановлены.

Для новой верхней панели требуется установка desktop `0.5.0-rc.2`: обновления веб-страницы недостаточно, поскольку панель принадлежит Electron. Общая главная загружается с сервера и доступна также в предыдущем desktop через переход на `/`.
