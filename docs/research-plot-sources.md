# Сюжеты серий для ИИ-чата под тайтлом (исследование, 2026-10-12)

Задача (IDEAS #5): чат под аниме, где локальная LLM отвечает на вопросы о сюжете («насколько оно душное», «о чём 5-я серия») с учётом того, что пользователь уже посмотрел (без спойлеров дальше).

## Вывод
Реалистично, покрытие — почти весь топ, не «10 тайтлов». Основа — описания серий TMDB (уже доступны через Seerr): EN почти у всех популярных, RU ~60–70%. Полные «скрипты» (субтитры) — только дополнительный слой для отдельных тайтлов.

## Проверено вживую
- **TMDB через Seerr** (`/api/v1/tv/{id}/season/{n}?language=ru|en`), 16 сезонов: EN-описание у 100% серий (110–440 символов); RU — полностью 10/16, частично 4/16, 0 у одного; RU короче, часто обрезанный тизер.
- **Kitsu** (`/api/edge/anime/{id}/episodes`, без ключа): описания у 9 из 10 популярных, только EN, ~100–240 символов.
- **Fandom** (MediaWiki API `action=parse`): подробные пересказы серий (Frieren/JJK/Vinland — 7,7–13 тыс. символов, One Piece ~2 тыс.), EN, CC BY-SA, структура у каждой вики своя.
- **AniList reviews** (GraphQL): у Frieren 500 рецензий по 3,5–23 тыс. символов — лучший источник для «душное ли» (обсуждают темп).
- **Jimaku.cc**: субтитры японские, нужен ключ, лимиты на IP; привязка к AniList/TMDB id.
- **Jikan**: через VPN — таймаут; по документации описания серий у MAL редки. **Shikimori**: описаний серий нет. **AniDB**: описаний почти нет, жёсткие баны.

| Источник | Данные | Язык | Покрытие топ-500 | Доступ | Усилия |

## Объёмы
- Описание серии 40–120 токенов → сезон 1,5–3 тыс. токенов, влезает в контекст без RAG.
- Пересказ Fandom 0,6–4 тыс. токенов на серию → сезон 30–60 тыс., нужен отбор.
- Субтитры ~4–8 тыс. токенов на серию → сжимать LLM по сериям (~300 токенов, ~10–15 с на серию на RTX 5080) + RAG на bge-m3 (100 тыс. чанков ≈ 200 МБ векторов).

## Рекомендация
1. **База**: описания серий TMDB (RU → EN), запасные TVDB (Sonarr) и Kitsu + описание тайтла. Без RAG.
2. **«Душное ли»**: 5–10 лучших рецензий AniList, заранее сжатых LLM в «темп, жанр, минусы» без сюжетных фактов (кэш на тайтл).
3. **Глубокий слой** (по требованию / для тайтлов из списка): Fandom или свои RU-субтитры → пересказ по сериям → RAG.

## Замер покрытия подробного сюжета (2026-10-26)
Выборка AniList TV: 20 популярных за последние полгода, 15 популярных старых (до 2024), 15 «середнячков» (места 300–1500).

| Источник | Свежие | Старые топ | Старые середина |
|---|---|---|---|
| Википедия EN, пересказ каждой серии | 19/20, ~1100 симв. | 13/15, ~1150 | 11/15, ~870 |
| Fandom, пересказ серии | 8/20, ~3300 симв. | 9/15, ~4700 | 4/15, ~3300 |
| TMDB EN (анонс серии) | 18/20, ~110 симв. | 11/15, ~170 | 14/15, ~170 |
| TMDB RU (анонс серии) | 5/20 | 4/15 | 0/15 |
| Kitsu (анонс серии) | 2/20 | 11/15, ~270 | 10/15, ~780 |
| Википедия RU (только общий «Сюжет») | 2/20 | 6/15 | 5/15 |

- Подробный сюжет есть почти везде, но только по-английски: Википедия EN — основной источник (редакторы пишут серии по ходу показа), Fandom — подробный слой для популярного. Счёт Википедии брал таблицы серий со всей страницы — мог засчитать соседний сезон, реальное покрытие чуть ниже.
- Русских пересказов серий нет нигде (у русской Википедии описаний серий нет ни в одной статье выборки) — русский пересказ делает LLM.
- Kitsu переехал на `kitsu.app` (нужен `Accept: application/vnd.api+json`); Jikan не отвечал ни напрямую, ни через VPN; Wikidata через VPN отдаёт 429 — русскую статью брать по межъязыковой ссылке английской.
- Объём: сезон из Википедии ~3 тыс. токенов, из Fandom ~12 тыс. — второе не влезает в контекст локальной модели (8 тыс.), кандидат для внешней LLM (задача `plot_deep`).

## Корпус серий — приёмка 7.12.1 (2026-10-26)
Сбор по 47 тайтлам (30 из списка admin, 15 свежих, 3 пилота), после доработок источников:

| Метрика | Порог | Факт |
|---|---|---|
| Серии с пересказом ≥ 300 симв. | ≥ 85% | 87% (47 тайтлов), 83% (30 тайтлов списка) |
| Серии с любым текстом | — | 100% |
| Верность сопоставления (серия подтверждена японским названием или датой ±1 день другого источника / расписания AniList) | ≥ 98% | 99,7% (2144 / 6) |
| Чужой сезон в корпусе | 0 | 0 (TMDB отдавал прошлый сезон у 3 тайтлов — пойман и отозван) |
| Ошибка «осталось» | ≤ 30% | 25–48% (выучивается скользящим средним) |

Что узнали:
- **Jikan закрыт 2026-10-01** (jikan-rest #613). Замены без ключа — Tenrai (`api.tenrai.org/v1`: дата, японское название, описание, флаги рекап/филлер) и Jikan-Edge (`jikan.lucashdo.com/v1`: только даты и названия). У MAL дата и японское название — у 100% серий, описание — у ~2/3, длинное (≥ 300) — у четверти. Страницы MAL напрямую не парсим. AniList как основной источник не меняем: альтернативы Jikan дают только серии MAL.
- **Даты AniList расходятся** с другими источниками (часовой пояс, переносы) — сопоставление сначала по японскому названию серии (нормализация с фуриганой `{{Ruby}}`), потом по дате.
- **Wikidata** часто без ссылки на enwiki у сезона: идём по P179 (сериал) и P144 (первоисточник), иначе поиск Википедии. **Fandom**: слаги вики не угадываются — поиск `services.fandom.com/unified-search` с проверкой совпадения названия.
- Пересказов нет ни в одном источнике у средних исекаев и не-японских тайтлов (Scissor Seven, Akashic Records, «7-й принц», The Strongest Magician, Faraway Paladin S2) — им нужны SDH-субтитры.

## Спойлеры
В контекст — только серии ≤ просмотренной (прогресс из списка; нумерация сезонов через `idmap.ts`); рецензии чистить от сюжета заранее; страницы персонажей Fandom не брать; в промпте запрет выдумывать события после серии N.

## Риски
TMDB — атрибуция; Fandom — CC BY-SA, вежливый парсинг; субтитры — авторское право (только локально); квоты OpenSubtitles/Jimaku/AniList; RU-описания короткие; Jikan недоступен через VPN.
