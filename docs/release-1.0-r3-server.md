## Проверенный инкремент R3.1, 20 ноября 2026

Установщик и публикация приняты в main через [PR #62](https://github.com/Valdemar58/home_theatre/pull/62).
Исходники кандидата: `b4cf8cbcf7592280bb9e403f3f0df03980f7b48a`.
[Сборка 44716739914](https://github.com/Valdemar58/home_theatre/actions/runs/44716739914)
завершилась успешно: полный CI, публикация GHCR, пакет установщика с checksum.

Образ:
`ghcr.io/valdemar58/home_theatre/server@sha256:895b1cc66863a5cdf668643937ddca0638fb3cbb564d09cb66552d1ec7eea72a`.

На отдельном Ubuntu 24.04 x86_64 проверены:

- Проверка checksum и установка без сборки приложения на VPS.
- Загрузка образа из GHCR без сохранённой авторизации в Docker.
- Запуск приложения и PostgreSQL, обе health-check успешны.
- Приложение доступно на loopback, PostgreSQL не публикуется на хосте.
- Отсутствие зависимости запуска от Jellyfin и Authentik.
- Восемь Linux contract tests установщика; shell syntax и Compose config.
- Конфигурация HTTPS проверена реальным Caddy через `caddy validate`.

В отдельном Compose-проекте с отдельной БД дополнительно проверены реальные HTTP:

- Регистрация даёт состояние ожидания; доступ к комнате до одобрения запрещён.
- Явное создание владельца, одноразовая настройка и авторизованный вход.
- Создание комнаты.
- Повторная установка не меняет хеши секретных файлов и конфигурации.
- После повторной установки сохраняются ID владельца, комната и сессия браузера.
- После перезапуска приложения сохраняются комната и сессия; новый вход работает.

Основной кандидат не содержит личной БД владельца. Данные текущей установки,
списки, история и привязки не переносились и не изменялись. Старая установка и
серверный медиапуть сохранены. Тестовый Compose-проект остановлен; его данные
оставлены для последующих проверок восстановления/обновления.

## Что ещё не принято и не проверено

R3.1 остаётся **в работе** до проверки публичного HTTPS по выбранному владельцем
тестовому домену и пользовательской приёмки установки. Проверка `caddy validate`
не подтверждает доступность DNS, выдачу сертификата или внешнюю сеть.

- Prowlarr и Ollama включаются установщиком, но полный сценарий их конфигурации,
  диагностики в админке и graceful degradation относится к R3.2.
- Найдены прежние условия доступности поиска, связанные с Sonarr, и ссылки
  на отсутствующие сервисы в `/api/me`; зафиксированы в #12 для R3.2.
- Нет заявления о готовности бэкапов, восстановления или окна обновления:
  R3.3 и R3.4 ещё не реализованы этим инкрементом.
- Не выполнена миграция рабочей БД на VPS; это отдельная проверка и последующий
  перенос принятого кандидата по плану выпуска.
- Установщик обнаружил уже установленный Docker на VPS. Ветка его установки
  через официальный APT-репозиторий пока не проверена на машине без Docker.
- Публичный пакет в Releases и стабильный выпуск остаются задачами R7;
  текущий пакет доступен как временный артефакт Actions.
