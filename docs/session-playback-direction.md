# Исполнение сеанса · M3

Mode: Operate. Расширение существующего плеера, без изменения визуальной системы PRODUCT.md/DESIGN.md. Пользователь подтвердил поведение и макеты переходов ранее; новый выбор направления не требуется.

Первый экран: видео остаётся ведущим, кнопка следующего пункта — в существующем меню плеера. После конца серии появляется компактная плашка с названием следующего пункта, общим отсчётом 10 секунд и отменой. Между тайтлами видео заменяется спокойным состоянием перерыва: название следующего тайтла, номер серии, крупное табличное время. Ниже — запуск сейчас и автовоспроизведение для управляющих. Без автоматического запуска — «Ожидание организатора». Финал содержит возврат в постоянную комнату.

Сигнатурное взаимодействие: один серверный отсчёт меняет контекст внутри живущей полноэкранной обёртки. Появление слоя — 220 мс с небольшим смещением и ease-out; reduced motion отключает анимацию. Время меняется без анимации цифр и не объявляется скринридером каждую секунду. Узкий плеер допускает внутренний скролл управления, не перекрывая доступ к действиям.

Палитра, типографика и Button наследуются из текущего интерфейса; нет новых брендовых цветов, свечений или стекла. Все действия используют текущие права комнаты. Ошибка команды остаётся рядом с действиями, а потеря связи явно приостанавливает локальное воспроизведение.

Не считать визуальное подтверждение доказательством синхронизации двух физических устройств или корректности кодеков: серверный сценарий проверяется отдельными интеграционными тестами, медиавоспроизведение — отдельно.
