# Magnet и контейнер плеера — 0.4.0-rc.2

2026-11-18. Дополнение к desktop-downloads-implementation.md; прежнее ограничение magnet-only снято.

## Изменения

- Поиск включает релизы с `magnetUrl`, даже без `downloadUrl`. Прежний torrent endpoint/ответ сохранён; magnet возвращается отдельным полем. Поддерживаются также magnet в downloadUrl, теле ответа и Location перенаправления Prowlarr. HTTP-редиректы на произвольный внешний сервер не выполняются.
- Поддерживается BitTorrent v1 info-hash (hex или base32; гибридные ссылки с btih подходят). Некорректный hash отклоняется. Ссылки xs/as/ws для произвольной загрузки метаданных/файлов удаляются; трекеры сохраняются для обнаружения пиров, включая необходимый им passkey. Prowlarr API-ключ не передаётся.
- Desktop получает metadata отдельным временным WebTorrent-клиентом без файлового хранилища и без выбора pieces. После metadata клиент закрывается, данные проходят существующую проверку имён/размеров и сохраняются как torrent descriptor. Дальнейший выбор/пауза/продолжение/подготовка используют тот же путь, что torrent-файл.
- Один запрос metadata за раз, тайм-аут 90 секунд, отмена ожидания и запроса к серверу, очистка сетевого клиента при завершении. Закрытие приложения отменяет получение метаданных. До выбора серии payload не скачивается.
- Ожидание и ошибка показаны у выбранной раздачи. После успешного получения доступны прежние checkbox, номера серий, общий объём и автоматическая подготовка.
- Чёрный прямоугольник на прошлом скриншоте был фоном растянутой grid-ячейки под плеером: правая колонка задавала высоту строки. `self-start` у stage сохраняет собственную высоту видео. Desktop: player и stage по 453.375px; узкий экран: оба 240px. Узкие полосы внутри видео при несовпадении пропорций остаются корректным object-contain, а не растянутым внешним контейнером.

## Проверки

- 12 desktop-тестов на Windows и Linux. Два настоящих loopback TCP-сценария: torrent и magnet → выбор серий 1/3 → пауза/продолжение → побайтовая проверка → подготовка callback → сохранение. Для magnet отдельно проверены нулевой payload до выбора, закрытие metadata-клиента, отмена и тайм-аут.
- 5 серверных тестов descriptor API: torrent-регрессия, права устройства/TTL, ошибки индексаторов, magnet-only, нормализация и redirect на magnet без второго HTTP-запроса. TypeScript и production Docker build успешны.
- Native UI: синтетический Prowlarr вернул magnet-only результат; desktop получил три файла, пользовательским кликом исключена серия 2, серии 1/3 скачаны до состояния готовности. Подготовленные совпадающие копии из предыдущей проверки библиотека повторно использовала.
- Браузер: проверена геометрия stage, реальные кадры существующего desktop-потока, desktop и 390px. Снимки в `.impeccable/review/magnet/`; основной `player-fixed.png` показывает устранение прежнего внешнего чёрного блока.
- Windows NSIS и Linux AppImage собраны; исходники и версия внутри ASAR совпадают с checkout. Обновление изолированной Windows-установки завершилось с кодом 0, установленный ASAR также сверен. Arch GUI и сеть друга по-прежнему не считаются проверенными.
- Независимый Impeccable finish-review: `ship` в рамках исправления геометрии плеера и добавленного UI метаданных. Ожидание/отмена оценены по коду, выбор и завершение — по native-снимкам.

## Использование

Обновить desktop до RC2. Найти тайтл и раздачу → «Выбрать серии» → дождаться списка файлов → отметить нужное → «Скачать на устройство». Для torrent-файла шаг получения метаданных от пиров не требуется. Нет пиров — список magnet может быть недоступен; это не означает, что раздача пуста.

Пакеты: `apps/desktop/release/home_theater-0.4.0-rc.2-win-x64.exe`, `apps/desktop/release/linux/home_theater-0.4.0-rc.2-linux-x86_64.AppImage`; контрольные суммы рядом в `SHA256SUMS-0.4.0-rc.2.txt`.
