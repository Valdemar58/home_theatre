# Редактор сеанса — направление реализации

Mode: Operate. Расширение существующего интерфейса, без смены DESIGN.md.

## Direction contract

THESIS: назначить вечер из нескольких произведений без ручного ввода диапазонов и переходов в загрузки.

OWN-WORLD: текущие Inter, тёмные поверхности и семантические OKLCH-тона; сдержанная элегантность. Primary только для сохранения, остальные действия спокойные.

STORY: пользователь задаёт время и пояс, добавляет тайтлы, выбирает серии слотами, переставляет блоки, назначает перерывы и видит пересчитанное окончание. Отмена сохраняет прежний план.

FIRST VIEWPORT: дата/пояс/окончание сверху, оценочный OP/ED ниже, вертикальные блоки слева и добавление тайтлов справа; на mobile одна колонка. Signature interaction — диапазон слотов на основе снимка pointerdown, доступный также одиночным нажатием и клавиатурой. Спокойное изменение цвета; reduced-motion.

FORM: согласованный пользователем session-editor.html, кодовая реализация существующей поверхности комнаты. Seed не применяется: направление и макет выбраны пользователем заранее.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Ограничения текущей вехи

Полноценный учёт результата групповых встреч — М4. Серые слоты пока прямо подписаны как прежний общий прогресс (минимум личных прогрессов), а не как подтверждённые результаты сеансов. Автоисполнение списка и синхронные перерывы — М3. Длительность из каталога, при отсутствии 24 минуты; OP/ED — оценочные 3 минуты, без вычитания из коротких серий до 3 минут. Будущие серии разрешены только по явно объявленному релизу, без экстраполяции недельного расписания.
