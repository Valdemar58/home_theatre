# Исправления входа desktop, уведомлений и навигации — 2026-11-19

## Результат
- Desktop 0.5.0-rc.4: адрес сервера → вход в окне приложения. Привязка не обязательна для входа; для локальных загрузок и удалённого управления: Настройки → Мои устройства → Подключить этот компьютер. Подтверждение использует ту же Electron-сессию. Cookies внешнего браузера не импортируются.
- Минимальный preload-мост предоставляет только запуск привязки и идентификатор текущего устройства; main проверяет окно, главный frame и origin сервера.
- Уведомления недоступности вынесены в Toast через portal над контентом. Каждый сервис: один показ за клиентскую сессию и минимум 24 часа между показами в этом профиле браузера. Закрытие вручную или через 12 секунд. Ограничение хранится в sessionStorage/localStorage; если хранилище заблокировано, доступна только защита в памяти текущего приложения.
- Барабан учитывает конец страницы и изменение её высоты. Короткий последний раздел больше не требует достижения верхней линии прокрутки.
- Seerr был остановлен пять дней. Контейнер запущен, /api/v1/status отвечает 200. Обновление приложения очищает прежнее состояние circuit breaker.
