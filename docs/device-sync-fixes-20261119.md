# Устройства, шкала диска и синхронизация серий — 19.11.2026

## Изменения
- Desktop 0.5.0-rc.5: вход в приложении → Настройки → Мои устройства → Подключить этот компьютер. Сверка кода с самим компьютером больше не нужна. Внешний старый flow сохранён для совместимости.
- Постоянный секрет установки хранится вне обычного профиля приложения (в тестах — внутри изолированного профиля). На сервере только SHA-256. Повторное подключение возвращает прежний device ID. Текущий аккаунт видит «уже подключён», другой — предложение явной отвязки. При перепривязке удаляются старые разрешения комнат, команды и снимок загрузок; файлы сохраняются. Токены и ключ не выдаются renderer.
- Старые дубли нельзя безопасно объединять по hostname: их можно отвязать вручную. Идентичность относится к установке в профиле ОС; переустановка ОС/удаление ключа или другой пользователь ОС не распознаются как тот же физический компьютер.
- Шкала диска: другие файлы → тайтлы в порядке списка → свободное место. Наведение/фокус на тайтле подсвечивает сегмент. Стандартная подсказка сегмента содержит название и размер. Изменение применяется и к серверным загрузкам.
- Ручной выбор серии, кнопка следующей серии и переход по плану используют общий серверный барьер загрузки подключённых зрителей. После готовности всех воспроизведение запускается автоматически. Сообщения и команды старой серии отбрасываются по поколению, тайтлу и номеру серии.
- Следующая серия во время отсчёта запускается немедленно, повторная старая команда не перескакивает ещё раз. На границе тайтлов ручное «следующая» из просмотра запускает плановый общий перерыв; из уже идущего перерыва можно перейти сразу. Автовоспроизведение перерыва сохраняет существующую серверную логику.
- Выбор серии из ленты в сеансе меняет текущий курсор исполнения; серия вне плана вставляется в текущую исполняемую копию после текущей. Сохранённый план встречи не переписывается, пропущенные серии не отмечаются просмотренными.
