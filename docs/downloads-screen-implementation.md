# Общий экран загрузок · 2026-11-18

Реализован в `/downloads` общими React-компонентами для браузера и desktop. Выбор устройства, поиск раздач, выбор файлов, torrent/magnet и прежний серверный путь сохранены.

## Поведение

- Дисковая сводка: фактические ёмкость и свободное место, известные файлы аниме по тайтлам, прочие файлы. Разные файловые системы показываются отдельно. Пути на компьютере не передаются серверу. Снимок обновляется раз в 30 секунд; у офлайн-устройства видна дата последних данных.
- Тайтл раскрывается в одну горизонтальную ленту серий. У каждой серии размер, полоса 80% скачивания + 20% подготовки, запуск готовой серии и спокойная иконка удаления. Повторные копии не увеличивают число серий; показаны количество копий и название раздачи.
- Для тайтлов, принятых в план комнаты, показаны аватарки участников: сначала не посмотревшие, затем посмотревшие с галочкой. Скрытый личный прогресс остаётся неизвестным. У предложений и тайтлов вне плана аватарок нет.
- Удаление конкретного скачанного файла проходит через подтверждение и постоянную очередь команд устройства. Остальные файлы сохраняются, раздача приостанавливается. Повтор команды безопасен. Подготовка или активная трансляция блокирует удаление.
- Для импортированного вручную файла удаляются запись библиотеки и подготовленная копия; оригинал сохраняется. Если одна запись библиотеки используется несколькими загрузками, оставшаяся идентичная копия сохраняет подготовленный файл.
- На медиасервере показываются подготовленные серии с возможностью удалить конкретную копию. Операция сначала снимает приоритет файла в qBittorrent; при недоступности загрузчика удаление не выполняется. Старая очередь источников доступна в раскрывающемся разделе. Это учёт известных подготовленных файлов, не полный аудит библиотеки Jellyfin.
- Личная и групповая история просмотра, комментарии и планы не удаляются вместе с файлами.

Для дисковой сводки и удаления на домашнем компьютере нужен desktop **0.5.0-rc.3** или новее. Старый формат отчётов принимается; отсутствие возможностей показано явно. Новых миграций БД нет.
