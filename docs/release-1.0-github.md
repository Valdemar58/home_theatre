- Логи/артефакты по умолчанию 14 дней. Для будущих временных установщиков явно
  задавать 7 дней. У GitHub Releases отдельный жизненный цикл.
- CI и Dependabot-конфигурация находятся в `.github/`.

## Ограничения текущей настройки

- Project V2 требует права `project`. Имеющаяся Git Credential Manager
  авторизация содержит repo/workflow/gist и получает INSUFFICIENT_SCOPES.
  Владелец настраивает GitHub CLI с нужным правом. Доска не считается созданной
  по одному включению настройки Projects в репозитории.
- До готовности доски используются временные status:* labels на Issues;
  после подключения Project статусы должны вестись там, без двух расходящихся
  источников истины.
- CI проверяет код, но не упаковывает и не публикует стабильный выпуск.
  Явный workflow кандидатов и безопасное обновление входят в дальнейшие этапы.
- Полный исходный пользовательский прогон R1.4 остаётся отдельной работой.
