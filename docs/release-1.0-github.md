  задавать 7 дней. У GitHub Releases отдельный жизненный цикл.
- CI и Dependabot-конфигурация находятся в `.github/`.

## Ограничения текущей настройки

- Project V2 управляется через авторизованный владельцем GitHub CLI с правом
  `project`. Старой авторизации Git Credential Manager этого права недостаточно.
  Статусы ведутся в Project; временные status:* labels больше не используются.
- CI проверяет код, но не упаковывает и не публикует стабильный выпуск.
  Явный workflow кандидатов и безопасное обновление входят в дальнейшие этапы.
- Исходный прогон R1.4 описан в [отчёте приёмки R1](release-1.0-r1-acceptance.md).
  Реальные сети и внешние интеграции остаются R6, конкретные пробелы — #37–#39.
