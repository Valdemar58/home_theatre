# Разностные обновления desktop · rc.20

## Что изменено

Разностная загрузка electron-updater включена. Generic feed использует
одиночные HTTP Range: поддержка проверена на реальном GitHub release asset
(206, ровно 1024 байта). Скачивается новый blockmap и только изменённые блоки;
полный установщик восстанавливается на диске и проверяется по SHA-512.
При ошибке дельты SDK переходит к полной загрузке с той же проверкой целостности.
До проверенного обновления клиент не подключается к аккаунту/API сервера.

Полный пакет по-прежнему нужен для первой установки, замены самого старого
обновлятора и восстановления при потере кэша. Обновлятор версий до rc.20
отключал дельту; исправить уже запущенный старый процесс новым пакетом нельзя.
Один раз установите локальный rc.20 поверх имеющегося приложения.

Локальный NSIS сохраняет соседний `<installer>.exe.blockmap` в update-кэш.
Карта должна соответствовать именно локальному EXE: независимая CI-сборка
с тем же номером может отличаться. При запуске EXE прямо из `release/` его
карта уже рядом; дополнительное ручное копирование не требуется. Если EXE
переносится отдельно, перенесите рядом и его `.blockmap`. У обычного
опубликованного установщика соответствующая карта доступна в GitHub Releases.

## Реальный прогон Windows · 2026-11-21

Проверены установленные NSIS-сборки с текущим клиентским кодом под отдельным
тестовым App ID: rc.20 → тестовый следующий пакет rc.21. Это настоящие
установка, скачивание, сборка установщика, запуск новой версии и чтение
сохранённого профиля; rc.21 из этого теста не публикуется как продукт.
Сервер обновлений локальный, диапазоны и неисправности контролируются тестом.
Личная установка пользователя, её профиль и привязки не изменялись.

Полный тестовый установщик: **241 216 392 байта (230,04 МиБ)**.

| Сценарий | Трафик файлов обновления | Полных загрузок | Результат |
| --- | ---: | ---: | --- |
| Дельта, карты с сервера | 1 816 287 байт / 1,73 МиБ | 0 | 8 Range, 1 309 049 байт изменённых данных + 507 238 байт карт; экономия около 99,25% |
| Карта от локальной установки, старая карта на сервере недоступна | 1 562 642 байта / 1,49 МиБ | 0 | Использован локальный sidecar, старую карту клиент не запрашивал |
| Повреждённые Range-ответы | 243 032 679 байт / 231,77 МиБ | 1 | Неверная собранная SHA-512 отклонена, полная загрузка и установка успешны |
| Удалён кэш старого EXE | 241 723 630 байт / 230,53 МиБ | 1 | Полная загрузка и установка успешны |

Это измеренные тела HTTP-ответов EXE/blockmap без заголовков и TLS;
маленькие запросы feed/API не включены. Другой инкремент, смена Electron,
FFmpeg или зависимостей дадут другой размер дельты — фиксированные 1–2 МиБ
для любого релиза не обещаются.

Во всех четырёх случаях проверены: активный профиль, cookie авторизации,
ID устройства, расшифровываемый safeStorage-секрет, дополнительные настройки,
задания загрузки и локальный файл. Команд повторной привязки не было.
Итоговый EXE в кэше совпал по SHA-512 с целевым пакетом.

Отдельный установленный security gate подтвердил: повреждённый итоговый пакет
не запускается, старый клиент не вызывает API, несовместимый новый клиент
остаётся заблокированным, анонимный handshake не передаёт cookie/токен.
После успешного обновления и совместимого handshake данные сохранены.
73 desktop-теста прошли. GUI/обновление на настоящем Arch этим прогоном
не проверялись; Linux остаётся preview.

## Повторение и артефакты

```sh
# Windows, из apps/desktop с подготовленными native dependencies
node test/installed-updates.mjs --differential --output ../../.local/differential-updates
node test/installed-updates.mjs --output ../../.local/installed-updates
```

Candidate CI выполняет оба gate и сохраняет отчёты, байты передач и трассы.
Сводка измерений: [desktop-differential-windows.json](evidence/desktop-differential-windows.json).
Локальные исходные артефакты: `.local/r6-differential/final-installed/`,
`full-integrity/`, `github-range-proof.json`, `build-win.log`.

Локальный Windows EXE и его blockmap находятся в `apps/desktop/release/`.
ASAR, версия, политика обновлятора и single-range publish config сверены
с исходниками. Сам локальный EXE остаётся полным установщиком; меньший
объём относится к последующим автоматическим обновлениям.
