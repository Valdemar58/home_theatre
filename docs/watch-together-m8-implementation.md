# М8 — итоговая проверка и release candidate

Дата: 2026-11-17. Desktop **0.3.1-rc.1**. Локальная техническая проверка завершена; полная эксплуатационная приёмка М8 остаётся открытой до Arch, WAN и нескольких реальных вечеров. Пользователь согласовал отложить проверку на настоящем Arch, поскольку устройства сейчас нет.

## Изменения

- Явный desktop-протокол `X-Desktop-Protocol: 2`. Сервер отклоняет устаревший heartbeat/транспорт с HTTP 426 и предложением обновления. Desktop показывает причину ошибки. Привязка и библиотека при несовместимости не очищаются.
- Готовность хоста требует свежего опроса совместимого транспорта, а не только перечня файлов. Старый клиент не отображается готовым к передаче.
- Убрана ошибочная транспортная ошибка до привязки аккаунта.
- Исправлены Windows-зависимое ожидание пути symlink в тесте и конфликт PostgreSQL sequence после fixtures с явными ID. Рабочие данные не менялись.
- Linux desktop filename согласован с упаковщиком. Собраны NSIS и AppImage; добавлены сценарий приёмки и preflight-скрипт.
- Добавлены регрессии готовности транспорта, несовместимости/восстановления клиента, обоих порядков тайтлов и отмены автоперехода при нулевом перерыве.

Последний браузерный прогон использовал один аккаунт и headless-хост на реальных desktop-модулях. Это не повтор полной двухклиентной приёмки М7 и не замер непрерывности при серверном рестарте. В М7 отдельно проверены два браузера и переход с Windows Electron на резервный relay-хост. Пауза при потере координации и порядок переходов проверены серверными тестами; полноценный повтор в реальной сети остаётся в приёмке.

Автотесты покрывают разреженные серии, оба порядка тайтлов, перерывы, отмену автоперехода, устаревшие события/ревизии, повторное завершение, DST gap/fold, права, общий барьер, отключение/возврат зрителя, независимую историю группы и личные циклы. Проверка этого на каждом реальном браузере не заявляется.

## Открытые ворота приёмки

1. Настоящий Arch: GUI, Wayland/X11, sandbox, keyring, установка/обновление. Отложено пользователем.
2. `https://pivocinema.duckdns.org/` снова дал connect timeout 15 секунд. Доступность извне, два NAT и прямое WebRTC-переключение между двумя нативными устройствами не подтверждены.
3. Несколько реальных вечеров с журналом; p95 синхронизации ≤500 мс и стабилизация ≤3 с не подтверждаются единичными локальными замерами.
4. Firefox, мобильные браузеры, ТВ, fullscreen-переходы и восстановление координации во всей матрице требуют ручного прогона. Responsive-проверка не заменяет испытание декодера и автовоспроизведения.
5. Desktop подключает существующие локальные файлы и готовит первую аудиодорожку. Встроенная загрузка раздач, другие дорожки/субтитры desktop-потока и полноценная desktop-обёртка веб-интерфейса не являются готовыми возможностями этой сборки.
