# М5 — устройства и локальная библиотека

Дата: 2026-11-17. Выпуск: 0.1.0-alpha.1. Сервер развёрнут на 5056.

## Реализовано

- Electron для Windows/Linux. Локальный renderer изолирован от удалённого веб-интерфейса; файлы выбираются системным диалогом, секрет устройства не передаётся renderer.
- Одноразовая привязка: 10 минут на подтверждение в браузере, сохранение назначения после входа. Сервер хранит хэш device token. Отзыв из «Мои устройства» прекращает доступ.
- Heartbeat каждые 5 секунд, офлайн после 45 секунд без heartbeat. Закрытие приложения прекращает работу; автоматического фонового хостинга нет.
- Реестр до 500 локальных серий, полный SHA-256 исходного файла, проверка изменений файла, подготовка MP4 встроенными FFmpeg/ffprobe, сохранение результата между запусками. Удаление записи не удаляет оригинал.
- Разрешения на конкретную пару тайтл/комната выдаёт только владелец устройства на устройстве. Членство и право хостинга проверяются повторно; организатор не может включить чужую библиотеку.
- Хосты комнаты: online-кольцо аватарки, ник и устройство, вертикальные тайтлы ближайшего сеанса, слоты серий, hover/focus и закрепление деталей нажатием. Без сеанса — только состояние устройства.
- Вход в управление устройствами из настроек и блока хостов.

## Пакеты и запуск

Файлы лежат в `apps/desktop/release/`: Windows `home_theater-0.1.0-alpha.1-win-x64.exe`, Linux `linux/home_theater-0.1.0-alpha.1-linux-x86_64.AppImage`. Контрольные суммы — `SHA256SUMS.txt`. Пакеты не опубликованы и не подписаны; автообновление не включено.

Windows: запустить установщик для текущего пользователя. Arch: разрешить выполнение AppImage и запустить. Проверка чистого Arch остаётся обязательной перед объявлением поддержки платформы. Не отключать Chromium sandbox ради запуска.

Установленный клиент требует HTTPS при новой привязке. Для проверки локального HTTP-сервера использовать разработческий `pnpm start`. Выбрать сервер → подтвердить устройство в браузере → найти тайтл → указать серию → подключить файл → подготовить → разрешить нужной комнате.

## Границы и остаточная приёмка

М5 не передаёт видео удалённому браузеру. Это М6, а автоматическая замена хоста — М7. «Подготовлено локально» не доказывает сетевую доступность.

Первая подготовка выбирает первую видео- и аудиодорожку; выбор дорожек и перенос субтитров в браузерный поток ещё не реализованы. Исходный файл сохраняется. Полный хэш исходника не гарантирует одинаковый таймлайн разных подготовленных копий.

Функциональная часть текущего захода реализована. Полная платформенная приёмка М5 остаётся открытой до проверки чистого Arch и обновления между версиями. Непроверенные пункты выше нельзя считать закрытыми только по успешной сборке пакетов.
