# Домашний кинотеатр — контекст для Claude

Общение с пользователем — **на русском**. Комментарии в коде — на русском, в стиле окружающего кода.

## Что это

Домашний кинотеатр на Docker Compose, разворачивается одной командой на новой машине (цель — Linux-мини-сервер / Linux-раздел dualboot):

| Сервис | Порт | Назначение |
|---|---|---|
| jellyfin | 8096 | медиасервер; библиотеки «Аниме», «Сериалы», «Фильмы», **«Стрим»** (`/data/media/stream`, .strm-файлы) |
| seerr | 5055 | запросы фильмов/сериалов |
| anime-calendar | 5056 | **свой сервис** `apps/anime-calendar` (Next.js 16), основная разработка идёт здесь |
| sonarr / radarr / prowlarr / bazarr | 8989 / 7878 / 9696 / 6767 | *arr-стек |
| qbittorrent | `${QBIT_WEBUI_PORT:-8090}` | торрент-клиент |
| flaresolverr | 8191 | обход Cloudflare для RuTracker |
| torrserver-core (+ stream-router) | 8092 (наружу), 6882 tcp/udp пиры | стриминг из торрента без скачивания (кэш — 1 ГБ в памяти на раздачу, диска нет); имя `torrserver` в docker-сети — у маршрутизатора `apps/stream-router`: скачанные серии («Подготовить», qBittorrent) он отдаёт с диска, остальное — в TorrServer |
| ollama | 11434 | локальная LLM (`qwen3.5:9b`) + эмбеддинги (`bge-m3`) |
| upscaler | — (внутри сети) | ИИ-апскейл картинок (Real-ESRGAN ncnn-vulkan, `apps/upscaler`); профиль `upscaler` (`COMPOSE_PROFILES`), без него всё работает |
| mapvec | — (внутри сети) | векторизация карт мира (`apps/mapvec`): подписи — dots.mocr (OCR с рамками строк, CUDA), суша и страны — SAM 2 + водораздел по пунктиру; профиль `mapvec`, без него карта мест — картинкой. Колёса CUDA — заранее в `apps/mapvec/wheels/` (`pypi.nvidia.com` отдаёт ~300 КБ/с на соединение), веса — `config/mapvec` |
| recyclarr | профиль `tools` | профили качества из TRaSH |
| caddy + ddns | 443 (наружу) | профиль `public`: календарь из интернета — `https://pivocinema.duckdns.org`, сервисы — на поддоменах (`auth.`, `jellyfin.`, `seerr.`, `sonarr.`, `radarr.`, `prowlarr.`, `bazarr.`, `qbit.`, `torrserver.`; Let's Encrypt TLS-ALPN, `apps/caddy/Caddyfile`), домашний IP → DuckDNS по STUN мимо VPN (`apps/ddns/ddns.mjs`); на Keenetic — проброс TCP 443 на `192.168.1.112` (из дома внешний адрес тоже работает) |
| authentik (+ authentik-worker, authentik-db) | 9000 | профиль `public`: единый вход (TASKS 7.9). Календарь и Jellyfin — OIDC, остальное — forward-auth в Caddy (служебные — только `kino-admins`, Seerr — и `kino-friends`). Настройка — `bootstrap.py --only authentik`, пользователями управляет календарь через API (служебная учётка `kino-calendar`); akadmin — служебный админ Authentik. База — Postgres на именованном томе (`backup.py` делает дамп) |

Оверрайды: `compose.nvidia.yml` (GPU для jellyfin и ollama), `compose.intel.yml`, `compose.vpn.yml`.

Скрипты (`scripts/`):
- `init.py` — создаёт каталоги `config/*`, `data/*` (включая `media/stream`), генерирует ключи в `.env`;
- `bootstrap.py` — настраивает всё через API: `--only <шаг>`; шаги: qbittorrent, sonarr, radarr, prowlarr, recyclarr, formats, jellyfin, bazarr, seerr, torrserver, ollama, anime-calendar;
- `backup.py` — архив конфигов (без `Definitions`, `ollama`, сокетов).

`.env`: `CONFIG_ROOT=./config`, `DATA_ROOT=./data`, `PUID/PGID=1000`, `TZ=Europe/Moscow`, ключи сервисов, `JELLYFIN_ADMIN_USER/PASSWORD`, `RUTRACKER_USER/PASSWORD`, `JELLYFIN_API_KEY`, `ANIME_CALENDAR_TORZNAB_KEY`, `LLM_MODEL`, `EMBED_MODEL`.

## Правила безопасности

- **Никогда не выводить** логин/пароль RuTracker, Jellyfin и прочие секреты из `.env` — только маскировать (`V***`). Скрипты читают `.env` сами.
- Email пользователя не отправлять во внешние сервисы.

## Git

## Решения пользователя (не переспрашивать)

- Русская озвучка в приоритете, с выбором студии; трекеры: RuTracker + публичные. VPN — опционально.
- Английские релизы в Sonarr — «оставить как есть».
- LLM — **только локальная** (Ollama), не Claude/облако.
- Стриминг — **TorrServer + Jellyfin**; смотреть — в **плеере календаря** (поток и перекодирование — Jellyfin), ТВ — приложения Jellyfin.
- Время в календаре — в поясе устройства (подпись «МСК», «МСК+2»).
- Списки: локальные + синхронизация с Shikimori; русские названия — Shikimori; оценки MAL/AniList.
- Вход — единый (Authentik, почта + пароль, без почтового сервера: ссылку сброса пароля выдаёт админ). Пользователи и приглашения — в календаре; приглашают все, админ одобряет, одобренный — сразу друг пригласившего.

## anime-calendar — устройство

Next.js 16 App Router, Tailwind v4 (`bg-linear-to-*`), TanStack Query, iron-session, SQLite через **`node:sqlite`** (адаптер в `src/server/db.ts`; better-sqlite3 убран — нативная сборка падала).
Docker: `NODE_OPTIONS="--dns-result-order=ipv4first --no-network-family-autoselection --disable-warning=ExperimentalWarning"` (иначе ETIMEDOUT на медленной сети).

- Хранилище внешних данных (TASKS 8.1): `server/cache.ts` — `cached(key, { fresh, source, cls }, fn)`: срок = «когда проверить снова» по живости тайтла (`lib/freshness.ts`), класс по ключу (`entity` — тайтлы, персонажи, серии — **не удаляются**; `listing`; `volatile`), устаревшее отдаётся сразу и обновляется в фоне; сбой источника не кэшировать как пустое (бросать `HttpError`, «нет данных» — пусто). Предохранители — `server/sources.ts` (`guarded(source, fn)`, `SOURCES_OFFLINE=anilist,shikimori,…` в env для проверки), `X-Data-Stale` → плашка `StaleBanner.tsx`. Архив тайтлов — `server/archive.ts` (очередь `archive_queue`, состояние `archive_state`, задача `archive` — кнопка на календаре), картинки списков закреплены (`img_cache.pinned`); `/api/health/sources` — состояние источников и архива.

Известные грабли:
- Правки с обратным слешем (`\b`, `\p{L}`) — только через Edit, не через heredoc/python (портит `\b` → backspace). В JS `\b` не работает с кириллицей — использовать `\p{L}`-lookaround.
- Prowlarr обрезает названия — полное название берём со страницы темы.
- Индексатор Sonarr блокируется после рестарта контейнеров — лечится тестом индексатора.
- Jellyfin 12 не перечитывает содержимое `.strm` после первого сканирования (ни при запуске, ни при Refresh, ни при сканировании папки) — менять, куда ведёт серия, только за ссылкой (маршрутизатор `stream-router`).
- MTU: docker-сеть проекта с MTU `${DOCKER_MTU:-1376}` (подбиралось под прежний VPN-туннель, под v2rayN/nekoray не перепроверялось); при 1500 TLS из контейнеров виснет (`UND_ERR_CONNECT_TIMEOUT` к Shikimori, 429/блок индексаторов). Менять MTU — только `docker compose down && up -d`.
- Jellyfin 12 перепроверяет `.strm` при каждом PlaybackInfo, а внешние файлы (озвучки, субтитры) ищет по своему кэшу списков папок (сброс после 5 мин без запусков): файл, положенный рядом с серией после первого запуска чего-либо из этой папки, не виден — поэтому ссылки на озвучки заводятся заранее.
- Jellyfin перед отдачей каждого сегмента HLS перебирает `/cache/transcodes`: тысячи файлов там (на Windows — bind-маунт) = десятки секунд на сегмент. Держится за счёт `EnableThrottling` + `EnableSegmentDeletion` (`bootstrap.py`); серия снова открывается медленно — сначала `ls /cache/transcodes | wc -l`.
- API Authentik (2026.8): фильтры списков работают не везде (`?name=` у провайдеров, `?group=` у привязок игнорируются — сверять у себя), приложения видны токену только с `superuser_full_list=true`; потоки и приложения адресуются по slug; у OIDC-провайдера нужен явный `grant_types` (иначе «Invalid grant_type»); `user_write` пишет в атрибуты только ключи `attributes.*`; текст статического поля — `initial_value`; ссылки из API (сброс пароля) строятся по адресу запроса — подменять на публичный. Jellyfin ходит к `auth.<домен>` по алиасу Caddy в docker-сети.
- Bazarr новых версий требует `audio_only_include` в элементах языкового профиля (иначе HTTP 500) — учтено в `bootstrap.py`.
- На Windows: SQLite-ошибки «locking protocol» у Jellyfin на NTFS-маунте, Docker-диск WSL (`ext4.vhdx`) только растёт — главная причина переезда на Linux.
- На Windows базу календаря (`config/anime-calendar/anime-calendar.db`, WAL) **не читать с хоста**, пока контейнер пишет: общая память WAL через границу Windows/Docker не видна, чтение даёт «database disk image is malformed» (сама база цела). Запросы — изнутри: `docker exec anime-calendar node -e` с `node:sqlite` и `/data/anime-calendar.db` (`readOnly: true`); целостность — `PRAGMA integrity_check`.

## Сеть и VPN

- VPN-клиент на хосте: Windows — **v2rayN**, Linux — **nekoray** (окончательный выбор не сделан). Сервер — VLESS + Reality.
- Правила маршрутизации **пользователь добавляет сам** в интерфейсе клиента; от Claude — готовые данные (в v2rayN поля Domain / IP / Process — через запятую, домен без префикса = совпадение по подстроке, `domain:` = домен и поддомены). После — проверить.
- v2rayN (`C:\Users\Valde\Desktop\v2rayN-windows-64`): настройки в `guiConfigs\guiNConfig.json` и SQLite `guiConfigs\guiNDB.db` (`ProfileItem` — серверы, `SubItem` — подписки, `RoutingItem` — наборы правил, `RuleSet` — JSON). `binConfigs\*` генерируются при подключении, править бесполезно. Базу читать только `mode=ro`; менять — лишь при закрытом v2rayN. Ключи серверов и ссылки подписок не выводить.
- Устройство v2rayN: TUN (sing-box, `configPre.json`) ловит весь трафик, его выход `proxy` → xray (`127.0.0.1:10808`, `config.json`) → сервер. Системный прокси тоже `127.0.0.1:10808`: через него Docker Desktop отправляет 80/443 контейнеров, минуя TUN. Правила v2rayN пишет в оба ядра. Трафик контейнеров в TUN виден как процесс `com.docker.backend.exe` (адрес контейнера не виден).
- Активный набор — «V4-全局(Global)»: всё через прокси, кроме исключений. Правила проекта (выше финального `proxy 0-65535`):
  1. `direct`, процесс `com.docker.backend.exe`, порты `1024-65535` — торренты из Docker; веб-запросы контейнеров (80/443) остаются в VPN;
  2. `direct`, домены `ghcr.io, lscr.io, pkg-containers.githubusercontent.com, ollama.com, ollama.ai, r2.cloudflarestorage.com, animego.me, animego.org, animelib.org, anilib.me, mangalib.me, ranobelib.me, cdnlibs.org, lib.social, imglib.info`.
- Проверка маршрута: clash API sing-box `http://127.0.0.1:10814/connections` (процесс, сработавшее правило, выход); для xray — куда `xray.exe` открывает TCP (`Get-NetTCPConnection -OwningProcess`): на IP сайта = `direct`. Мимо VPN с хоста — `curl.exe --interface <IP Wi-Fi>`. Пробный контейнер — `curlimages/curl`.
- Доступность напрямую (проверено 2026-10-26): Docker Hub, RuTracker, TMDB — обрыв TLS, AniList — 11 с вместо 1 с; всё это только через VPN (не добавлять в обход). Напрямую работают ghcr.io, lscr.io, Ollama, Shikimori. AniLib/AnimeGo — геоблок, только мимо VPN; AnimeGo недоступен вообще.
- Почему торренты мимо VPN: через VPN ~1,3 МБ/с (серия стрима требует ~1 МБ/с — остановки), напрямую ~31 МБ/с.
- Адреса торрент-контейнеров закреплены (torrserver `<DOCKER_NET>.0.250`, qbittorrent `.251`, подсеть `<DOCKER_NET>.0.0/16`; `DOCKER_NET` по умолчанию `172.25`, на Windows `172.30` — 172.25 занят `docker_gwbridge`) — для правил по адресу источника на Linux. Смена подсети/адресов требует `docker compose down && up -d`.
- nekoray (Linux): правила под проект не настраивались.
- Lib-API (`api.cdnlibs.org`) требует браузерные `Referer`/`Origin` (иначе 403), `Site-Id: 5` — AniLib. AniList отклоняет стандартный User-Agent urllib.
- zsh: не называть переменную `path` (связана с `PATH`).
